00 / How to read it

Connection is not control.

An MCP badge alone tells you almost nothing. An official server can be read-only, limited to an allowlist, or capable of launching and deleting campaigns. A community wrapper can expose a vendor API without becoming vendor-supported.

Official
Documented by the vendor or maintained in its verified source-code organisation.
No official MCP verified
None found in this review. It is not a claim that no community implementation exists.
Read + write
Can create, update, launch or delete connected objects. Review gates matter.
