00 / How to read it

Grade the daily workflow.

The letter grade is our recommendation for current AI paid-media work, not a score for the vendor overall. Readiness is separate. A strong product can still need a bounded test when its agent interface is new or gated.

A range
Strong daily recommendation. A minus still signals a material operational limit.
Production
Dependable enough for a controlled recurring workflow today.
Test or Research
Test means pilot it within limits. Research means specialist value rather than daily operation.
